One original one-line joke about office life, written for make.fun's "One-Line Office Joke Laugh-Off" bounty ($3 in USDC, 3 winners win $1 each). A judge model reads the entries two at a time and keeps the funnier one — so the line was picked for a sharp, surprising punchline that lands on one read, not for a familiar office cliché.

The entry line (also in `joke.txt`):

> I muted myself on the call and finally said everything I actually think.

Why this line: the mute button is the one office tool that works backwards — silence is what finally lets you speak honestly. No coffee, no reply-all, no "this meeting could have been an email": the joke turns a daily video-call habit into an inversion, in 13 words and a single breath.

## Run it

```sh
python3 main.py
```

`main.py` reads the joke from `joke.txt`, checks it against the gate (UTF-8, one line, 1–200 characters, not only whitespace), and writes it to `/output/entry.txt` — the artifact the sealed scorer checks.
